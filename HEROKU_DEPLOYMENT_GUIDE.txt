📋 SIMPLE 5-STEP PROCESS
================================================================================

STEP 1: MongoDB Atlas Database
├─ Go to: https://www.mongodb.com/cloud/atlas
├─ Create cluster (free)
├─ Create user & get connection string
└─ TIME: ~5 minutes

STEP 2: Heroku Login
├─ Command: heroku login
├─ Browser opens, login with credentials
└─ TIME: ~1 minute

STEP 3: Create Heroku App
├─ Command: heroku create kaamconnect-api
├─ Get URL: https://kaamconnect-api.herokuapp.com
└─ TIME: ~1 minute

STEP 4: Set Environment Variables
├─ DATABASE_URL, JWT_SECRET, API KEYS, etc.
├─ Commands: heroku config:set KEY="value"
└─ TIME: ~2 minutes

STEP 5: Deploy Code
├─ Command: git push heroku main
├─ Wait for build (2-3 min)
├─ Deployment complete!
└─ TIME: ~3 minutes

TOTAL TIME: ~10-15 minutes

================================================================================
✅ DEPLOYMENT CHECKLIST
================================================================================

BEFORE DEPLOYMENT:
  □ Heroku account created (free at heroku.com)
  □ Heroku CLI installed (https://devcenter.heroku.com/articles/heroku-cli)
  □ MongoDB Atlas account created (free at mongodb.com)
  □ Git installed and configured

DURING DEPLOYMENT:
  □ MongoDB cluster created
  □ Database user created
  □ Connection string copied
  □ Heroku app created with: heroku create kaamconnect-api
  □ Environment variables set with: heroku config:set
  □ Code deployed with: git push heroku main
  □ Build completed successfully

AFTER DEPLOYMENT:
  □ Verify app running: heroku ps --app kaamconnect-api
  □ Check logs: heroku logs --tail --app kaamconnect-api
  □ Test API: curl https://kaamconnect-api.herokuapp.com/health
  □ Verify database: MongoDB Atlas Collections tab
  □ Update Flutter app: Change kBaseUrl in api_client.dart

================================================================================
🔑 ENVIRONMENT VARIABLES YOU'LL NEED
================================================================================

DATABASE_URL
  └─ Connection string from MongoDB Atlas
  └─ Format: mongodb+srv://user:pass@cluster.mongodb.net/db

JWT_SECRET
  └─ Strong random string (20+ characters)
  └─ Example: "your-super-secret-key-change-this"

NODE_ENV
  └─ Set to: "production"

GOOGLE_MAPS_API_KEY
  └─ Get from: Google Cloud Console (optional)

OPENAI_API_KEY
  └─ Get from: openai.com (optional)

GOOGLE_AI_API_KEY
  └─ Get from: ai.google.dev (optional)

CORS_ORIGIN
  └─ Your Flutter app URL when deployed
  └─ Example: "https://your-flutter-app.com"

See .env.example for complete list

✨ QUICK VERIFICATION
================================================================================

After deployment, verify with these commands:

Check app is running:
  heroku ps --app kaamconnect-api
  Expected: web.1: up

View logs:
  heroku logs --tail --app kaamconnect-api
  Expected: No error messages

Test API:
  curl https://kaamconnect-api.herokuapp.com/health
  Expected: HTTP 200 OK

View environment variables:
  heroku config --app kaamconnect-api
  Expected: All variables you set

Check database:
  Go to MongoDB Atlas → Collections
  Expected: Data being created
